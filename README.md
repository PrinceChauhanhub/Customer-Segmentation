# Customer Segmentation Project  

This project is focused on customer segmentation using machine learning techniques. It aims to analyze customer data to identify distinct groups for targeted marketing and business strategies.  

## Notebook Overview  
The included Jupyter Notebook (`notebook.ipynb`) contains the following sections:  
- Data Import and Preprocessing  
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Customer Segmentation using Machine Learning  
- Results and Insights  

## How to Run  
1. Install the required dependencies:  
    ```
    pip install -r requirements.txt
    ```
2. Open the notebook:  
    ```
    jupyter notebook notebook.ipynb
    ```

## Dependencies  
- Python 3.11  
- Jupyter Notebook  
- Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, K-Means, PCA 

## Usage  
This project can be used to:  
- Analyze customer behavior  
- Identify distinct customer segments  
- Develop targeted marketing strategies
